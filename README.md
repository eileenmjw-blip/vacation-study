# 방학 한 달 파이썬 완주 플랜

**시작일**: 2026-07-24 | **기간**: 4주 (24일 학습 기준, 하루 1시간)
**목표**: 전공 과제 수준의 프로그램을 스스로 짤 수 있는 실력 만들기
**진단 결과**: 코드를 읽고 논리를 설명하는 건 잘하지만(함수 기본값 인자, 인덱스 에러 등 정확히 이해), 직접 손으로 코드를 완성하는 연습이 부족함(리스트에 값 추가하기, 문법 디테일 등). → **이 플랜은 "듣기"보다 "직접 타이핑해서 실행하기"에 압도적으로 비중을 둡니다.**

## 진행 방식

1. 매일 `weekN/dayNN/lesson.md` 를 읽는다 (10분 내외, 짧게)
2. `weekN/dayNN/practice.py` 를 VSCode로 열고 `TODO` 부분을 직접 채운다
3. VSCode에서 실행해서 결과를 확인한다 (아래 실행법 참고)
4. 다 풀면 대화창에 "Day N 다 풀었어" 라고 알려주면 코드 리뷰 + 다음 날 자료 생성

막히면 언제든 그 자리에서 질문하면 됩니다. 정답을 바로 주기보다 힌트부터 드릴게요.

## VSCode에서 파이썬 실행하는 법

- **방법 1 (추천)**: 파일 열고 오른쪽 위 ▶ (Run) 버튼 클릭, 또는 `F5`
- **방법 2**: 상단 메뉴 `터미널 > 새 터미널` 연 다음 `python day01/practice.py` 입력
- **에러가 나면 당황하지 말고 맨 아래 줄부터 읽기**: 보통 마지막 줄에 어떤 에러(`SyntaxError`, `IndexError` 등)인지, 몇 번째 줄(`line __`)인지 나옵니다. 이걸 읽는 연습도 이번 학습의 일부입니다.
